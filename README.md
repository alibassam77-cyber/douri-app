# عيادة - Clinic | نظام حجز وطوابير العيادات

تطبيق ويب لحجز مواعيد العيادات وإدارة طابور الانتظار لحظة بلحظة.
المريض يحجز من هاتفه ويتابع دوره والوقت المتبقي، والطبيب يدير الطابور من لوحة تحكم خاصة به.

رابط المشروع الحي: ضع هنا رابط 【entity-GitHub¦canonical_name=GitHub】 Pages الخاص بك بعد النشر
مثال: https://username.github.io/douri/

---

## المميزات

### للمريض
- البحث عن الأطباء بالاسم أو التخصص
- الفلترة حسب المدينة
- ترتيب العيادات حسب الأقرب إليه
- عرض العيادات على الخريطة
- حجز موعد مع اختيار اليوم من تقويم يوضح الأيام المتاحة والمكتملة
- تذكرة حجز فيها: رقم الدور، عدد المنتظرين أمامه، وقت الانتظار التقريبي، موعد الكشف المتوقع، عدّاد تنازلي
- رمز سري من 12 رقم لاستعادة الحجز من أي جهاز
- مشاركة التذكرة عبر واتساب
- إلغاء الحجز
- تنبيهات: قبل 45 دقيقة من الموعد، عندما يبقى 3 أمامه، وعندما يحين دوره
- يعمل بالعربية والإنجليزية مع وضع ليلي / نهاري

### للطبيب
- إنشاء حساب عيادة برمز تفعيل
- إضافة أكثر من عيادة لنفس الحساب
- تعديل بيانات العيادة: الاسم، المدينة، الشارع، أوقات العمل، مدة الكشف، أيام العمل، الموقع على الخريطة
- فتح / إغلاق العيادة مؤقتا
- نداء المريض التالي أو نداء مريض محدد
- إنهاء الكشف لمريض واحد أو إنهاء الكل
- تأجيل مريض لنهاية الطابور مع إعادة ترقيم صحيحة
- حذف عيادة كاملة مع كل حجوزاتها بعد كتابة عبارة التأكيد: إحذف العيادة
- حذف سجل الطبيب بالكامل عند حذف آخر عيادة لديه، مع إمكانية إعادة التفعيل بنفس البريد وكلمة المرور

## الملفات

| الملف | الوظيفة |
| :--- | :--- |
| `index.html` | الواجهة الرئيسية للمريض + بوابة الأطباء |
| `admin.html` | لوحة تحكم الطبيب |
| `script.js` | منطق واجهة المريض والحجز وبوابة الأطباء |
| `admin.js` | منطق لوحة تحكم الطبيب |
| `lang.js` | كل الترجمات العربية والإنجليزية |
| `style.css` | كل التنسيقات والوضع الليلي |
| `firestore.rules` | قواعد أمان قاعدة البيانات في Firebase |

---

## التقنيات المستخدمة

- HTML / CSS / JavaScript بدون إطار عمل
- Firebase Authentication لتسجيل دخول الأطباء
- Cloud Firestore لحفظ الأطباء والعيادات والحجوزات
- Leaflet + OpenStreetMap للخرائط
- Font Awesome للأيقونات
